# ASI FPB Mains Trainer

Hosted static trainer for Telangana SCT ASI (Fingerprint Bureau) mains preparation.

## Training order
Official syllabus learning → shortcuts/traps → source-traceable PYQ-derived questions → model drills → topic tests → cumulative timed exams → strict full mocks.

## Question provenance
- 2023 Paper II: selected Booklet-A questions are included as faithful English paraphrases from published question-paper transcripts. Each carries the original year, booklet, question number and source link.
- 2023 Paper III: the official TSLPRB preliminary answer key is linked. Questions are **not** reconstructed or invented from the answer key.
- AI/model practice questions are always labelled Model and kept distinct from PYQs.

## Progress
Progress is stored in browser localStorage. Use Export/Import JSON to move progress between devices.

## Branch
This trainer is isolated on the `asi-fpb-trainer` branch so the repository's main privacy-policy content remains untouched.
